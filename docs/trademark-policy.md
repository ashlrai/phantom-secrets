# Project name and logo use

The MIT License governs the repository materials to which it applies. It does
not authorize someone to imply project endorsement, official status, or a
commercial relationship that does not exist.

This page is practical public guidance for using the Phantom project name and
logo. It is not a statement that a mark is registered, not a transfer of rights,
and not legal advice.

## Uses that normally do not need advance permission

You may:

- truthfully state that software uses, integrates with, or is compatible with
  Phantom, provided you do not imply endorsement;
- link to the official repository or documentation;
- discuss, review, teach, or report on the project;
- identify an unmodified fork as a fork of Phantom while making its independent
  status prominent; and
- use the unmodified project logo at a reasonable size to identify a truthful
  link or reference to the official project.

Keep attribution accurate. Do not use styling, domains, account names, or copy
that could make an independent distribution appear official.

## Ask before uses that create source confusion

Request written permission before using the Phantom name or logo:

- as the primary name of a company, paid product, hosted service, package,
  application, domain, event, or certification program;
- in a modified or combined logo;
- on merchandise or paid promotional material;
- to suggest sponsorship, approval, partnership, certification, or official
  support; or
- in a way likely to confuse users about who publishes, secures, supports, or
  operates the offering.

A fork may keep the code under MIT while using a distinct product identity.
Removal of project branding does not change the copyright and license notices
required by the MIT License.
